## Native exceptions

Canonical Studio Lumen role/base24 schemes stay unchanged. SystemUIFont is the
native font exception outside Dot matrix. The latter embeds unmodified licensed
Departure Mono (`assets/fonts/README.md`), samples its 11px grid at 3x, and uses
pitch 3, fractional gap 0.25 and corner fraction 0.34: 2.25px cells, 0.75px gaps,
0.765px corner radius. The native stage is opaque black; both lit/unlit cells,
letters and caret are pixels. Suggestions remain ordinary readable native rows.

The real native Input owns editing/selection/IME. Pixel ink follows native glyph
and range geometry; covering occurs only with a complete supported mask. Visible
native fallback is mandatory for composition/non-ASCII/unsupported geometry.
The pixel caret is steady, not the native blink animation, during this trial.

Lens alone requests native OS blur with role-derived tint/shadow; this is not
Apple Liquid Glass. Slot/Corners/Notch use native geometric decoration. Focused
non-matrix inputs have a short baseline marker. None of these decorations proves
OS material fidelity or other-platform behavior.

A bounded native contrast pairing correction leaves tokens untouched: light
Signal uses opaque canonical paper ink on the accent field; light open-input
placeholders use foreground rather than muted ink; light list metadata uses
foreground (retaining semibold tool emphasis) on both selected and unselected
rows so hover selection also remains readable. Dark list accents are unchanged.
These exceptions respond to measured native-scene contrast, not palette redesign.

## Evidence and limits

Actual hidden macOS GPUI scene renders cover all ten idle/suggestion states in
Lumen Dark at 680 logical pixels and Lumen Light at 480. GPUI-dispatched Enter
checks cover all ten local choices; synthetic scenes do not use model transport
or desktop capture. Contact sheets composite alpha onto labeled synthetic matte.
Source and exact capture hashes live in Studio, alongside the bounded finish
review and light-contrast confirmation. These are native renders, not browser
mocks, and not OS-compositor/backdrop proof.

Build/tests and dispatched keys do not prove physical keyboard/on-screen focus,
selection/scroll alignment, real IME/dictation, VoiceOver, OS blur, all-background
contrast or other-platform runtime acceptance. Those remain explicit gates.
Probabilities and timeout select previews, never grant execution authority.
Tinycast supplied material/interaction principles only; no AGPL code was copied.
